# X0 Report — Decomposing the one-step ECG failure (WildPPG primary; DaLiA secondary)

> **Metric semantics note (added 2026-08-31).** In this document `morph` / `morphology_corr` is
> **matched-beat morphology correlation** and `rr_mae_ms` is **matched-consecutive-beat RR MAE**. Both are
> conditional on successful ≤50 ms one-to-one R-peak matching and are averaged only over matched beats.
> A missed beat therefore incurs no explicit penalty in either metric — it is excluded from the denominator
> rather than scored — so neither metric is monotonic in event coverage: both may rise or fall when the
> matched set changes. Values and specifications here are unchanged; only the labels and their scope are
> made explicit. See [METRIC_SEMANTICS.md](METRIC_SEMANTICS.md).


Pre-registration: `docs/X0_ERROR_DECOMPOSITION_PREREGISTRATION.md` (commit `f7e0c9d`, pushed before any X0 metric was computed).
Analysis-only experiment on frozen prediction arrays; nothing was trained or regenerated. All numbers: `artifacts/x0_error_decomposition/`
(`summary.json`, `*.csv`, `figures/`). Generated by `scripts/analyze_x0_error_decomposition.py` (ORACLE DIAGNOSTICS — every alignment uses the
ground truth and is never a deployable metric; the frozen evaluation semantics of A0–A9 are unchanged).

## 1. Verdict (frozen rules, §"Frozen decision rules" of the pre-registration)

| dataset | MSE | OT-CFM-1 | iMF-1 | overall (OT1 ∧ MSE) |
|---|---|---|---|---|
| **WildPPG** (primary, 3,907 windows, 40,523 GT beats, 8 subject×site clusters) | EVENT-DOMINANT | EVENT-DOMINANT | EVENT-DOMINANT | **EVENT-DOMINANT** |
| DaLiA S2 (secondary, 1,025 / 10,748) | EVENT-DOMINANT | EVENT-DOMINANT | EVENT-DOMINANT | EVENT-DOMINANT |
| DaLiA S1 (secondary, 1,151 / 10,988) | EVENT-DOMINANT | EVENT-DOMINANT | EVENT-DOMINANT | EVENT-DOMINANT |

**What the verdict means in these data.** "EVENT-DOMINANT" was triggered by the pre-registered *oracle-absent* rule: for ≥ 50 % of ground-truth
R-peaks the prediction contains no ECG-like structure anywhere within ±150 ms (best-translated correlation < 0.5 **or** peak-to-peak amplitude
< 20 % of the GT beat). For OT-CFM-1 this holds for 76 % of GT beats (MSE 88 %; the 50-NFE reference 38 %). The absence is **not** selective beat
dropping: the per-beat amplitude distribution of OT-CFM-1 is unimodal near zero (10th–90th percentile of the oracle-aligned peak-to-peak ratio
0.07–0.44; only 5.8 % of beats reach ≥ 0.5, vs 84 % for OT-CFM-50; MSE 0.9 %). Every beat is present as a small, smooth deflection and no beat
is present as a QRS. Timing, by contrast, is the one component labelled LOW for MSE and OT-CFM-1 (matched-peak MAE 19–20 ms, bias ≈ 0). The
pre-registered dominant-deficit ranking therefore names **sharpness** (deficit 0.97 MSE / 0.89 OT1), then amplitude (0.91 / 0.84), then event
(0.88 / 0.76), then shape (0.65 / 0.60), and timing last (0.39 / 0.38). H-X0-TIMING is not supported; H-X0-EVENT (in the sense of uniformly
sub-threshold beats) and H-X0-SHAPE (attenuation/sharpness loss that survives every oracle translation) describe the same finding.

## 2. Central question

> When OT-CFM-1 looks visually "completely wrong", is the correct ECG-like structure actually present nearby in time, or has that structure itself been destroyed?

**It has been destroyed, not displaced.** Allowing each GT beat its own best integer translation within ±150 ms (translation only, no scaling),
OT-CFM-1's segment retains a median 16 % of the GT peak-to-peak amplitude, 3 % of the QRS (±100 ms) energy and 11 % of the maximum slope; the
50-NFE reference under the identical oracle retains 88 % / 81 % / 86 %. Global alignment (±250 ms) raises OT-CFM-1's frozen morphology from
0.379 to only 0.420 (cluster-bootstrap Δ = +0.018 [0.010, 0.029]); local oracle translation raises beat correlation from 0.13 to 0.40 but the
same oracle raises OT-CFM-50 from 0.06 to 0.57, so the OT1–OT50 gap *widens* after alignment (raw gap −0.07 → aligned gap +0.17; paired
cluster-bootstrap Δ oracle beat corr OT1 − OT50 = −0.175 [−0.203, −0.147]). The R-peaks OT-CFM-1 does produce are as well timed as OT-CFM-50's
(MAE 19.2 vs 21.4 ms; SD 23.5 vs 25.7 ms), and its global lag is centred on 0 ms. The one-step output is a temporally correct, low-amplitude,
low-slope envelope of the ECG; nothing sharper exists in it at any nearby offset.

## 3. Provenance and protocol (frozen)

`prediction_provenance.json`: sha256 of every prediction array, checkpoint, split manifest and test-input file; all four arms use identical test
windows (verified). Models: MSE = A6 full-backbone regressor (a6c / a6a / a6b), OT1 = OT-CFM Euler-1, iMF1 = iMeanFlow-1, OT50 = OT-CFM Heun-25
(50 NFE); noise seed 0. Detector = frozen `rpeaks.detect_rpeaks` (neurokit) on both signals; matching 50 ms one-to-one; global lag ±32 samples
(±250 ms) by normalised cross-correlation on the overlap with explicit crop (no wrap-around); local translation ±19 samples (±150 ms) by Pearson
correlation, GT-anchored beat window (−0.25 s, +0.40 s), edge beats skipped and counted (WildPPG: 37,342 of 40,523 GT beats analysable per model,
identical set for all models); QRS ±100 ms; HF > 15 Hz; oracle-absent = corr < 0.5 ∨ p2p < 0.2; cluster bootstrap over 8 (subject, site) clusters,
2,000 resamples, seed 0; frozen qualitative windows WildPPG [2439, 297, 415], S2 [880, 482, 824], S1 [1067, 726, 221]. No parameter was changed
after the results were seen. Unit tests: `tests/test_alignment_diagnostics.py` (8 tests, pass).

## 6. Level-by-level results

**Level 1 (raw, frozen semantics).** Reproduces A4/A6: MSE RMSE 0.350 / morph 0.316 / amplitude 0.19 (median) / QRS-energy retention 0.07 /
slope 0.05 / F1 0.421; OT1 0.355 / 0.379 / 0.25 / 0.12 / 0.15 / 0.481; iMF1 0.485 / 0.551 / 1.00 / 1.18 / 1.08 / 0.385; OT50 0.440 / 0.670 / 0.97
/ 0.78 / 0.96 / 0.440. HF (> 15 Hz) energy ratio: GT 0.328; MSE 0.015, OT1 0.101, iMF1 0.292, OT50 0.295.

**Level 2 (global oracle lag).** Δ_global morphology +0.019 [0.006, 0.037] (MSE), +0.018 [0.010, 0.029] (OT1), +0.017 (iMF1), +0.012 (OT50):
statistically non-zero, practically negligible, and the same size for every model. Globally aligned RMSE changes by < 0.02 for all models. A
single window-level lag explains none of the one-step gap.

**Level 3 (event timing, frozen detector).** Matched-peak timing error is indistinguishable across models (MAE 19–22 ms, bias −6…+0 ms, SD
23–26 ms). Detector "missing" is high for every model including the reference (0.54–0.63) and therefore non-discriminative; the discriminative
event quantity is the detector-independent oracle-absent rate (0.38 / 0.52 / 0.76 / 0.88). Spurious peaks are *fewer* for the one-step models
(0.32) than for iMF1/OT50 (0.55): one-step outputs are too flat to trigger the detector, while iMF1/OT50 add extra sharp deflections.

**Level 4 (beat-centred oracle shape).** At the exact GT coordinates every model correlates ≈ 0 with the GT beat (0.05–0.13) — the PPG-conditioned
placement is offset by tens of ms for all of them. After the ±150 ms oracle translation: OT50 0.571, iMF1 0.481, OT1 0.400, MSE 0.348. The
retention ratios (table §4) separate the models by an order of magnitude: OT1/MSE keep 0.03/0.01 of the QRS energy, iMF1 0.50, OT50 0.81.
Per-beat amplitude distributions (`posthoc_p2p_distribution_wildppg.json`, a post-hoc summary of the pre-registered per-beat quantity): fraction
of beats with oracle p2p ≥ 0.5 — MSE 0.9 %, OT1 5.8 %, iMF1 76.9 %, OT50 84.0 %; fraction < 0.2 — 77 %, 59 %, 2 %, 5 %. One-step attenuation is
uniform across beats, not a mixture of full-amplitude and missing beats.

**Recoverable gap fraction.** Not computable as pre-registered: `raw_gap` (OT50 − model, beat corr at the same coordinates) is −0.043 (MSE),
−0.065 (OT1), +0.013 (iMF1), all below the 0.05 stability floor, because the same-coordinate correlation is ≈ 0 for the reference as well.
Reported honestly as UNSTABLE; the decision did not depend on it (the oracle-absent rule fired first). The interpretable substitute is the
*aligned* gap, which is large and precise (OT1 −0.175 [−0.203, −0.147]; MSE −0.225 [−0.277, −0.177]; iMF1 −0.091 [−0.105, −0.076]).

**RMSE decomposition.** RMSE is lowest for the flattest model (MSE 0.350 < OT1 0.355 < OT50 0.440 < iMF1 0.485) and barely moves under global
alignment (−0.004 … −0.017). QRS-region RMSE is larger than non-QRS RMSE for every model (0.435/0.44/0.585/0.547 vs 0.34/0.348/0.48/0.425); under
oracle local translation the QRS RMSE ordering inverts (OT50 0.387 < OT1 0.402 < MSE 0.411 < iMF1 0.454). RMSE rewards suppressing the QRS; the
pointwise-error inversion of A5/A6/A9 persists and is not a timing artefact.

## 7. OT-CFM-1 vs MSE

Waveform RMSE between the two 0.078 (PCC 0.51) before, 0.080 (PCC 0.41) after each is globally aligned to the GT — alignment does not make them
more alike because they are already nearly identical; the small drop in PCC comes from independent, ill-defined lags for near-flat signals.
Differences in median amplitude 0.06, QRS energy 0.06, slope 0.11, oracle beat correlation 0.05 (paired OT1 − MSE +0.051 [0.018, 0.095]). Both fall
in the same category on all three datasets. OT-CFM-1 is marginally less attenuated than the MSE proxy but qualitatively the same object.

## 8. iMF-1 residual

iMF-1's beats exist with full amplitude and slope (LOW deficits, 0.80 / 0.81) but retain only half the QRS energy (0.50 vs 0.81) and 52 % of GT beats
are oracle-absent (vs 38 %), driven by correlation (52 % of beats < 0.5) rather than amplitude (2 % < 0.2): the deflections are present but often
mis-shaped or placed as extra spikes (spurious 0.56; visible in window 297). Timing MODERATE and equal to OT50's. The residual iMF1–OT50 gap
(−0.091 [−0.105, −0.076] in oracle beat corr) is a shape/placement residual, not an attenuation.

## 9. OT-CFM-50 (reference)

Oracle-absent 38 %, oracle beat correlation 0.571, shift median 47 ms / SD 74 ms, 7 % of shifts at the limit. The reference is itself imperfect on
WildPPG, so absolute LOW/MODERATE/HIGH labels overstate every model's failure; the model-relative retention ratios are the reliable readout.

## 10. DaLiA S2 / S1 (secondary)

Beat-level temporal correspondence is less reliable under the current raw PPG-DaLiA evaluation protocol (oracle shift median 78–86 ms and 10–22 %
of shifts at the ±150 ms limit even for OT-CFM-50; same-coordinate beat correlation ≈ 0 for all models; timing MAE 25 ms identical across models).
Within that caveat the pattern is the same and stronger: MSE / OT1 oracle-absent 1.00 / 1.00 (p2p 0.02 / 0.07, QRS energy 0.00 / 0.00, slope 0.01 /
0.05); iMF1 / OT50 0.63 / 0.63 (p2p 0.66 / 0.78, slope 0.61 / 0.70). Global alignment adds +0.06–0.11 morphology for every model (larger window-level
lags on DaLiA, again model-independent). Category EVENT-DOMINANT for all three one-step models on both subjects; no timing component distinguishes
one-step from 50-step.

## 11. What the data support / do not support

Support: (i) the visual failure of OT-CFM-1 (and MSE) on WildPPG is uniform attenuation of the QRS deflection — amplitude, QRS energy and slope an
order of magnitude below the 50-NFE reference at *every* translation within ±150 ms; (ii) the timing of the beats that are produced is as accurate
as the reference's, and a window-level lag explains almost nothing; (iii) OT-CFM-1 ≈ MSE proxy before and after alignment; (iv) iMF-1 preserves
amplitude/sharpness and its residual is shape/placement; (v) RMSE ranks the flattest output best under every alignment.
Do not support: any claim about *why* one-step transport attenuates (no mechanism was tested); any statement that timing ambiguity, phase modes or
multimodality cause the collapse (not measured); between-seed generality (single training seed per model); DaLiA beat-level timing claims.

## 12. Limitations

Oracle alignments use the ground truth and are diagnostics only. WildPPG GT (kjd) is noisy — 38 % oracle-absent for the reference. The pre-registered
recoverable-gap fraction is unstable by construction in these data (same-coordinate correlation ≈ 0 for all models); the aligned gap replaces it.
Cluster bootstrap over 8 clusters is coarse. The oracle-absent definition (corr < 0.5 ∨ p2p < 0.2) is one frozen threshold; the per-beat
distributions show the conclusion does not hinge on it (5.8 % vs 84 % of beats above p2p 0.5).

## 13. GO / STOP

Pre-registered branch for EVENT-DOMINANT: "event-generation/count modelling first". Applied literally this would be misleading here, because the
events are not selectively missing — they are uniformly sub-threshold. The evidence therefore also satisfies the substantive content of the
SHAPE-DOMINANT branch (retention ratios far below 0.5 × OT50 for all three measures). Consequently: **X1 (controlled temporal-ambiguity synthetic
experiment) is NOT justified** — no timing-recoverable component exists to isolate. If anything follows, it is a pre-registered question about
what the one-step transport loses — which PPG-conditioned information determines QRS amplitude/sharpness and why the one-step map suppresses
it while iMF-1 does not — not a timing or event-alignment method. No experiment is started; the program stops here as instructed.
