## 2. Audit corrections and disclosures (audit text at `7526201` left as written)
1. The V1 split permutes patients (sorted unique `subjectid`), not cases (audit wording).
2. Full-split S = 1 waveforms exist for iMF and CD on validation and test (`outputs/ed1_cache/`, float16, seeds 0–15);
   the audit said none. Not used.
3. During iMF / PENGUIN training every 5th validation window (965 / 4,822) fed a no-grad loss that selected
   `checkpoint_best.pt`; the evaluated `checkpoint_last.pt` weights do not depend on it; `checkpoint_best.pt` supplies only
   architecture config (sha256 I `09aef613…`, C `a0824340…`). CD never read validation data.
4. Test HR rows 0–15 mix provenance (batch 64 / 512 / 128) and storage precision (float32 / float64): differences
   ≤ ~1e-5 bpm, but they turn exact ties into near-ties (see D7).
5. Common random numbers across splits: for every arm, validation window i and test window i share the initial noise z0
   of a given seed (`randn(N,…)` is a prefix-consistent stream); CD's re-noise tensors are drawn after z0 at a
   split-dependent offset and are **not** shared. `bootMedInstab` uses the same resample indices for the same
   (condition, row index, partition) on both splits. The partition list and the bootstrap both start from
   `default_rng(20260924)` (independent uses). None of this carries labels; disclosed.
6. **The test set is not fresh at condition level.** Seeds 0–15 of these test windows, the same HR functional and the
   same 12 conditions were analysed in DW1 / EXP-B / B3 (e.g. condition-level spread and ρ̄ ordered the consensus gain).
   Between-condition agreement in M1 is therefore a re-observation, not new evidence — hence D3.
7. The partition rule's chosen reading: `a = sorted(rng.choice(16, 8, replace=False))`, then `A_p = rng.permutation(a)`
   (stored order defines `splitHalfInstab`). The literal "choice order" reading would give a different list; the list
   was fixed once before any metric. "Balanced" means |A| = |B| = 8; per draw, A-membership ranges 11–22 of 32.

## 3. Deviations from `7526201` (prospective; each with its reason)
- **D1 — statistics are computed within each partition, then averaged over the 32 partitions** (overrides frozen §8 /
  §9 "average predictions and targets over the partitions, then compute metrics"). Reason: averaging both sides over
  partitions makes the unit-level prediction and target functions of the same 16 draws (A_p and B_q overlap for p ≠ q),
  which manufactures association. Synthetic null with the frozen partition list, log1p MAD(A) as the only predictor and
  no real window-level signal: mean per-partition Spearman **+0.003 / +0.007** (Gaussian / t3) vs Spearman of
  partition-averaged values **+0.173 / +0.295**; the three reviewers found the same (up to +0.84 with outliers). For
  every partition p each (condition, window) unit enters once with pred(A_p) against G(B_p): no pseudoreplication and
  A/B disjoint. The frozen averaged statistics are still reported, labelled **"reuse-contaminated, non-gating"**.
- **D2 — α criterion** = row-level (partition-level) out-of-fold MAE of G_B, i.e. the literal frozen §6 criterion
  (= mean over partitions of per-partition MAE). GroupKFold(5) by patient, all rows of a patient in one fold; ties →
  smallest α; refit on all validation rows.
- **D3 — within-condition requirement.** Because pooled statistics can be met by condition-level structure already seen on
  this test set (§2.6) and captured by log S, STRONG additionally requires the **within-condition Spearman** (mean over the
  12 conditions of the per-condition Spearman, per partition, averaged over partitions) to have a CI lower bound > 0.
  If the pooled criteria pass but this does not, the verdict is PARTIAL, labelled "between-condition only". A baseline
  **B5 = log S only** (same pipeline) is reported with the paired pooled difference B3 − B5.
- **D4 — informativeness gate** (frozen §10 stops only if the consensus fails to beat the constant). Tightened, as in
  `65dcc97`: Gate A = paired patient-bootstrap CI of MAE(consensus) − MAE(constant) entirely below 0; **Gate B (added)** =
  Spearman(consensus, reference) CI lower bound > 0. Consensus = median of the 16 draws; constant = median of `ref_hr` over
  all 4,822 validation windows. Evaluated pooled over the 12 conditions (stop rule) and per condition (conditions failing
  Gate A are flagged, and the verdict is also reported without them). The gate result is written and committed **before**
  any test feature table is built; if it fails, no test feature table is built and M1 is UNINTERPRETABLE.
- **D5 — FAILED operationalised so each route can fire:** (a) pooled Spearman point ≤ 0; (b) "top and bottom quartiles do
  not differ" = quartile-contrast point ≤ 0 (symmetric with (a); a positive point with a CI including 0 is PARTIAL);
  (c) "collapse out of validation" = the paired patient-bootstrap CI of MAE(B3) − MAE(B0) on test is not entirely below 0
  (the frozen predictor is not better than the validation-mean constant out of validation); (d) **0 of 3** model-specific
  Spearman point estimates > 0 ("pooled association is between-model only"; frozen text covers only "one model").
- **D6 — MAD-only clause** (frozen §12 says STRONG iff four criteria yet PARTIAL if "B1 matches B3"): resolved as the brief
  words it — STRONG is downgraded to PARTIAL only if MAD-only works (B1 within-condition Spearman CI lower bound > 0) **and**
  the within-condition paired difference Spearman(B3) − Spearman(B1) has a CI lower bound ≤ 0. Within condition log S is
  constant, so B3 cannot beat B1 through depth alone.
- **D7 — HR snapping.** Every HR value (validation and test banks, references) is rounded to 1e-3 bpm before any feature or
  target is computed (far above the ~1e-5 provenance noise, far below the HR lattice spacing), so ties are treated alike on
  both splits. Ranks use average ranks for ties.
- **D8 — quartiles.** Cut-offs recomputed per partition and inside every bootstrap replicate from the (label-free)
  predictions, with the inverted-CDF quantile (weights = bootstrap multiplicities); top = pred ≥ q75, bottom = pred ≤ q25;
  n_top / n_bottom reported.
- **D9 — cross-fitted mechanism** (frozen §10 averaged ρ_A and G_B over partitions, which removes the cross-fit): for each
  partition p, Spearman over the 12 conditions of ρ_{A_p} (mean pairwise Pearson across the condition's windows of the
  errors of the 8 A draws) against G_{B_p} (window-mean held-out gain), then the mean over p; same for the swap ρ_{B_p} →
  G_{A_p}, pooled and within model (4 points). Descriptive only, no verdict role; expected sign negative; bootstrap CIs are
  labelled as stability of a fixed set of conditions; a permutation p (100,000 condition-label permutations) for the
  12-point pooled statistic; a depth-adjusted variant (partial Spearman given log S). Primary split test, validation
  reported. It is a re-analysis of draws already used in B3 / B3-BOOT.

## 4. Operational definitions (not deviations)
1. Rows: per condition, windows in Ω_HR (reference and all 16 draws finite, frozen); one row per (condition, window,
   partition). `bootMedInstab` exactly as frozen (`default_rng([20260924, cond_idx, window_row_index, part_idx])`, 64
   resamples, window_row_index = index in the split's `load` order).
2. Baselines: B0 = mean validation G_B; B1 = [log1p MAD]; B2 = [log1p SD]; B5 = [log S]; B3 = all ten; same
   StandardScaler + Ridge pipeline and α search for B1–B5.
3. Per partition p, over the pooled test units: Spearman, Pearson, MAE, R² of pred_B3(A_p) vs G(B_p); quartile contrast;
   model-specific Spearman (the model's units, its four depths pooled); within-condition Spearman (mean over the 12
   conditions); the same for B1, B2, B5, B0 (MAE); paired differences. Headline = mean over the 32 partitions.
4. Bootstrap: 5,000 replicates, `default_rng(20260924)`; each draws the 1,156 test patients with replacement; a patient's
   multiplicity weights all of its units in every condition (mapping by `pid`, independent of load order); every
   headline statistic is recomputed as the mean over partitions within the replicate; 95 % percentile CIs; CIs condition
   on the frozen predictor.
5. Verdict, evaluated in order: **FAILED** if any of D5 (a)–(d); else **STRONG** if pooled Spearman CI lower > 0, quartile
   contrast CI lower > 0, ≥ 2 of 3 model-specific Spearman > 0, within-condition Spearman CI lower > 0 (D3), and the D6
   downgrade does not apply; else **PARTIAL** (with its label). Every outcome maps to exactly one category. The verdict
   reads only G_B-based statistics.
6. Secondary targets (descriptive, non-gating, scored with the frozen G_B predictor, no refit): Spearman of pred_B3(A_p)
   with Grel_B(p) (ε = 1.0 bpm) and with Δ_width(p); **Δ_width shares A with the features and is not cross-fitted**.
7. Leave-one-model-out: α re-selected by the same CV on the other two models' validation rows; test = the held-out
   model's units (pooled and within-condition Spearman, per partition, averaged); all three directions.
8. Extended depth-probe (secondary): conditions S ∈ {1, 2, 4}; rows need all 16 draws finite at S and at 2S; the four
   probe features on A appended; B3 refit on exactly these rows as comparator; per-model results; CD's pairing is z0-only
   (its re-noise tensors enter at t = j/S vs j/2S), so an iMF + PENGUIN-only sensitivity is reported. Cost 8·(S + 2S).
9. Sign decision: omitted (frozen §9.5); no τ, including τ = 0, is computed.
10. Sensitivities (non-gating): (a) common window set Ω_∩ (finite in all 12 conditions); (b) deployable view — per
    condition the share of windows with A and reference finite but ≥ 1 B draw non-finite (selection on future
    finiteness); (c) patient-macro Spearman (per (patient, condition) means); (d) frozen-§8 averaged statistics
    ("reuse-contaminated"); (e) verdict without conditions failing Gate A (D4).
