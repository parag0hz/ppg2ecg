## 1. 방법: 1스텝 생성기의 합의 추론

```
같은 PPG ─► 노이즈 ①  ─► [1스텝 생성기] ─► ECG 샘플 ①  ─┐
     …                                        …          ├─► 모으기 ─► 최종 답
같은 PPG ─► 노이즈 ⑯  ─► [1스텝 생성기] ─► ECG 샘플 ⑯  ─┘
```

| 단계 | 내용 |
|---|---|
| 1. 1스텝 생성기 | 신경망 1회 호출(1 NFE)로 ECG를 만드는 모델. iMF, consistency distillation(CD), reflow, 소형 DiT를 같은 조건에서 비교. **모두 기존 기법** |
| 2. 샘플 K개 | 같은 PPG에 노이즈만 바꿔 K = 16개 생성 (총 16 NFE. 기준 모델 PENGUIN은 1개에 50 NFE) |
| 3a. **심박수 합의** (주 결과) | 샘플별 심박수의 **중앙값** |
| 3b. **합의 디코딩** (확장, 조건부) | 샘플들의 R 피크 위치를 ±50 ms 창에서 투표 → 과반(θ·K표) 위치를 비트로 확정 → 각 샘플의 비트를 **정렬 후 평균**해 파형 생성. 파라미터는 VitalDB 검증 환자에서만 선택 후 고정 (iMF: θ = 0.375, CD: θ = 0.25) |

**계보:** 음성인식의 consensus decoding(Mangu 2000), MBR 디코딩, LLM의 self-consistency(Wang 2023)와 같은 계열.
PPG→ECG에서 여러 샘플의 *분류 점수*를 평균한 선행 연구(UA-P2E, Belhasin 2024)와 달리 **이벤트 단위**로 모으고
**계산 예산을 맞춰** 비교합니다.

**공통 학습 조건:** PENGUIN 백본(Flow-SSM/S5, 4.30 M params), 4초 창 @ 128 Hz, AdamW 1e-3, batch 64, **정확히 14,000 step**,
seed 42(주요 arm은 seed 3개), 같은 step 시점의 체크포인트로 비교.

## 2. 데이터셋 (PPG → ECG, 전부 피험자 단위 분리)

| 데이터셋 | 환경 · 센서 | 원본 샘플링 (PPG / ECG) | 피험자 | train / val / test (피험자) | test 창 수 | 분리 방식 |
|---|---|---|---|---|---|---|
| **VitalDB** | 수술실 · 손가락 PPG | 500 / 500 Hz | 5,782명 (6,043 케이스) | 4,337 / 289 / **1,156** | 19,543 | 환자 ID 기준 단일 분리 |
| **WildPPG** | 야외 웨어러블 · 4부위 | 128 / 128 Hz | 14명 (`kjd`·`ssx` 제외) | fold당 8~9 / 2 / 3~4 | 피험자당 3,000 | **4-fold, 14명 전원 1회씩 test** |
| **BIDMC** | 중환자실 · 손가락 | 125 / 125 Hz | 51명 (각 8분) | 31 / 5 / **15** | 1,800 | 단일 분리 |
| **CapnoBase** | 수술·마취 · 손가락 | 300 / 300 Hz | 42명 (각 8분) | 25 / 4 / **13** | 1,560 | 단일 분리 |
| **PPG-DaLiA** | 일상 웨어러블 · 손목 | 64 / 700 Hz | 15명 | 9 / 2 / **4** | 9,040 | 단일 분리 |

- 전처리는 전 데이터셋 공통: PPG 0.5–4 Hz 대역통과, ECG 0.5 Hz 고역통과, 창 단위 z-score 후 [−1, 1] 정규화, 128 Hz 리샘플.
- PPG-DaLiA는 손목 PPG와 가슴 ECG가 다른 기기라 **초 단위까지만 동기화**됩니다(비트 단위 지연 500–640 ms, 시간에 따라 드리프트).
- VitalDB는 마취 중 환자라 리듬이 규칙적이고 부정맥이 거의 없습니다(수술 전 ECG 99%가 정상 동리듬).

## 3. 주 결과 — 심박수 합의 (5개 데이터셋 전부에서 PENGUIN 50 NFE보다 정확)

단위 bpm, 낮을수록 좋음. 차이의 95% 신뢰구간은 피험자 단위 bootstrap.

| 데이터셋 | PENGUIN 50 NFE | iMF 1 NFE (샘플 1개) | **iMF 16샘플 합의 (16 NFE)** | 합의 − PENGUIN-50 | 피험자별 승률 |
|---|---|---|---|---|---|
| VitalDB | 9.69 | 10.14 | **6.67** | **−3.01** [−3.13, −2.90] | 94% |
| WildPPG | 13.66 | 12.61 | **9.27** | **−4.39** [−4.89, −3.89] | 100% (14/14) |
| BIDMC | 8.93 | 7.94 | **6.53** | **−2.41** [−3.52, −1.12] | — |
| CapnoBase | 7.54 | 6.75 | **5.51** | **−2.05** [−4.20, −0.29] | — |
| PPG-DaLiA | 13.42 | 16.74 | **12.70** | **−0.72** [−1.29, −0.20] | — |

- CD 합의는 4/5에서 유의(CapnoBase만 −0.26 [−1.19, +0.71]).
- **seed 재현(VitalDB, seed 42 / 1 / 2):** 합의 HR 6.68 / 6.28 / 6.36, PENGUIN 50 NFE 9.69 / 11.04 / 11.19. 세 주장(비열등, 합의 우위, 소형 DiT 우위) 모두 **3/3 재현**.

## 6. 확장 결과 — 합의 디코딩 (조건부)

사전등록 기준: 자기 단일 샘플 대비 F1 +0.05 이상 **그리고** 형태 상관 +0.15 이상.

| 데이터셋 | F1 (단일 → 디코딩) | F1 개선 | RR-MAE (ms) | 판정 |
|---|---|---|---|---|
| VitalDB | 0.674 → 0.765 | **+0.091** | 20.8 → 10.8 | F1 통과 · 형태 미달(+0.118) → PARTIAL |
| WildPPG (파라미터 재조정 없이 전이) | 0.371 → 0.439 | **+0.068** | 27.0 → 18.6 | F1 통과 · 형태 미달 → PARTIAL |
| BIDMC | 0.584 → 0.604 | +0.020 | 14.7 → 14.7 | 기준 미달 |
| CapnoBase | 0.652 → 0.664 | +0.012 | 12.1 → 11.1 | 기준 미달 |
| PPG-DaLiA | 0.147 → 0.125 | **−0.022** | — | **해로움** (HR 16.7 → 24.1) |

- **작동 조건:** 샘플들이 비트 위치에 합의해야 합니다. DaLiA는 PPG–ECG 동기화가 거칠어 16개 샘플의 투표가 창 전체에 흩어집니다(`artifacts/qual_by_dataset/`의 7번째 행 참고).
- 비트별 신뢰도 신호는 약합니다(투표 위치 SD와 타이밍 오차의 Spearman +0.07). 투표율 75% 필터로 정밀도 0.84 → 0.89.

### HRV (VitalDB, 연속 2분 블록 1,224개)
| 방법 | SDNN 오차 (ms) ↓ | RMSSD 오차 ↓ |
|---|---|---|
| PENGUIN 50 NFE | 81.2 | 106.6 |
| iMF 단일 | 87.3 | 114.6 |
| PRV (PPG 피크만, 모델 없음) | 62.7 | 81.1 |
| **iMF 합의 디코딩** | **55.3** | 74.8 |
| **CD 합의 디코딩** | **54.0** | **72.4** |

상대 우위는 모두 유의하지만, **정답 SDNN 중앙값이 54 ms인데 오차도 54 ms**라 임상적으로 쓸 수준이 아닙니다.

## 7. 개인화 분석 (학습 없음, 정답 위치를 준 상태에서 형태만 비교)

| 템플릿 | 보정 ECG | 비트 형태 상관 ↑ | 전역 대비 |
|---|---|---|---|
| 전역 (학습 환자 200명 평균) | — | 0.660 | — |
| 개인 | 4초 | 0.654 | −0.006 (역효과) |
| 개인 | 8초 | 0.680 | +0.021 |
| 개인 | 16초 | 0.708 | +0.048 |
| **개인** | **32초** | **0.728** | **+0.069** (oracle 격차의 36%, 아직 포화 안 됨) |
| oracle (그 창 자체) | — | 0.851 | +0.191 |

- 생성 모델의 같은 지표는 0.15~0.36입니다(위치 오차 포함). 환자의 99.6%에서 "정답 위치에 템플릿 찍기"가 어떤 생성기보다 낫습니다.
- 난이도 지표 SBV(개인 내 비트 변동): 어려운 환자는 전역 0.579 → 32초 보정 0.652에 그치고, 메우는 비율도 가장 작습니다(33% 대 41%).

## 8. 효과가 없었던 시도 (모두 VitalDB, 같은 예산)

| 시도 | 결과 |
|---|---|
| 백본 4배 확대 (4.3 M → 17.1 M) | **악화** (HR +0.32, F1 −0.028) |
| S5 → self-attention | 변화 없음 (HR −0.77은 마진 미달, FD 악화, 속도 2.1배) |
| 공식 iMF-DiT 구조 (소형 / B/2) | HR과 F1을 맞바꿈 (HR −1.2~−1.5, F1 −0.04~−0.05) |
| ImageNet 사전학습 가중치 (8,814만 파라미터 이식) | 변화 없음 (처음부터 학습한 같은 구조 대비) |
| KAN 피드포워드 (KANFlow 설계, outer / all) | iMF: 변화 없음. PENGUIN: HR +1.36 (seed 편차 범위 안) |
| 구조 가중 손실 · 엔드포인트 일관성 손실 (M2, M3) | 둘 다 기준 미달 |
| α·MAE + (1−α)·(1−PCC) 보조 손실, 스펙트럼 손실 (LW1) | **진행 중** (2026-09-21 밤 완료 예정) |

**공통 결론:** 한계는 모델의 표현력이 아니라 **PPG에 담긴 정보**입니다. 성능을 실제로 움직인 것은 추론 방식(합의)뿐이었습니다.

## 10. 한계
1. 샘플 1개만 쓰면 PENGUIN 50 NFE에 지는 피험자가 더 많습니다(VitalDB에서 iMF 승률 41%).
2. 파형 모양은 PPG에서 복원되지 않습니다. ST 변화, QRS 폭 같은 진단 정보는 주장할 수 없습니다.
3. 심박수만 필요하면 PPG 피크 세기로 9.06 bpm이 나옵니다. 합의(6.2~6.7)만 이를 확실히 앞섭니다.
4. 부정맥 환자 데이터에서 검증하지 않았습니다.
5. reflow·CD·WildPPG·BIDMC·CapnoBase·DaLiA는 단일 seed입니다.
